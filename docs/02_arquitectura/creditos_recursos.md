# Créditos y recursos visuales

Este documento identifica el origen de los recursos de JORGE'S MUSIC HOME y las condiciones aplicables a cada grupo.

## Imágenes de la interfaz

Según confirma el propietario del proyecto, las siete imágenes se generaron mediante ChatGPT con las herramientas de generación de imágenes de OpenAI para JORGE'S MUSIC HOME. Fachada y Recepción también incluyen manifiestos C2PA que identifican la herramienta de generación.

| Archivo | Uso |
| --- | --- |
| `fachada-principal.png` | Fachada y acceso a la tienda |
| `recepcion-principal.png` | Recepción y panorámica de Nuestra historia |
| `recepcion_fija_sin_marcos.png` | Interior estático visible al abrir las puertas |
| `vitrina_guitarras.png` | Acceso a la sala de guitarras |
| `vitrina_bajos.png` | Acceso a la sala de bajos |
| `vitrina_teclados.png` | Acceso a la sala de teclados |
| `vitrina_baterias.png` | Acceso a la sala de baterías |

## Ilustraciones de Mundo Musical

Las doce ilustraciones editoriales también se generaron para el proyecto con herramientas de imágenes de OpenAI. Corresponden a guitarra, bajo, teclado, batería, fonógrafo, vinilo, Woodstock, hip-hop, Walkman, MIDI, gusanos musicales y La 440. Las escenas históricas son ilustraciones editoriales. [Documentación de Mundo Musical](../04_casos_de_uso/mundo_musical.md) · [Archivos de las ilustraciones](../../instrumentos/static/instrumentos/img/mundo)

Las imágenes generadas se incluyen como parte de la identidad visual del proyecto. Su inclusión no concede una licencia abierta sobre ellas ni transfiere derechos sobre materiales de terceros.

## Modelos tridimensionales

Los cuatro modelos proceden de Innerscene y están documentados bajo **CC0 1.0 Universal**.

- `solid-body-electric-guitar.glb`
- `four-string-bass-guitar.glb`
- `88-key-keyboard-instrument.glb`
- `five-piece-drum-kit.glb`

Las fichas de origen y los hashes se conservan en la [documentación de recursos 3D](recursos_3d.md).

## Biblioteca Three.js

La galería utiliza **Three.js 0.180.0**, con su licencia **MIT** y el aviso de los autores incluido en el repositorio. [Aviso MIT de Three.js](../../instrumentos/static/instrumentos/vendor/three-0.180.0/LICENSE.txt)

## Código propio

El código propio carece de una licencia abierta general. Las condiciones de las imágenes, los modelos y las dependencias se aplican por separado.
